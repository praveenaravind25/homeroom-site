Ambient v2 · spreads + drift

Every screen covers all 1263×841 px. Each cell is cut to a camera ratio (3:4, 1:1, 3:2, 3:1), so most photos land with almost no crop. A pure function compose(queue, config) → screen chooses the layout.

Composer (pure, tested; look-ahead 8 picks)

  1. Classify: L 1.2 ≤ r ≤ 2 · P r ≤ .85 · S .85–1.2 · W r > 2.
  2. The head pick sets the layout. Partners must belong together (≤72h apart, or a shared person; never the same burst). Partners are pulled forward in the queue, never skipped.
  3. Prefer the layout with the most photos that fits the crop budget: a photo loses ≤ 25% of its area, unless its focus box survives.
  4. Rhythm (config ["spread","spread","hero"]): after two spreads, a strong landscape gets the whole wall. More photos, with a breath.
  5. Nothing fits → hero (L), sweep (W) or tilt (P). Never a visible backdrop.

Drift: one personality, varied per cell

FeelA slow breath, not a show. Ping-pong sweeps of 32s on sine in-out, so you notice it on a second glance, not from the sofa.
Faces safeZooms scale about the focus point (transform-origin), so faces stay fixed while the frame tightens. Pans scale about the centre and travel ≤ (scale−1)/2, so edges never show.
CounterpointNeighbouring cells always move in opposite directions, and each starts at a different phase, so they never turn around together. One lead cell (the largest) does the Ken Burns.
ArrivalThe settle (1100 fade · 1400 settle) runs on the settler, and the drift is already running on the mover inside it, so a photo arrives moving. Cells settle in reading order, 120ms apart. The outgoing screen keeps drifting while it fades. Freezing it would read as a hitch.
OverlayNever moves (only the stepped burn-in drift). The photo moves, the clock doesn't.
ReducedNo drift, no settle transform. Opacity crossfades only.

Overlay over seams

  • Horizontal seams sit at y ≈ 420. Both text clusters start below y ≈ 500, so they never cross one.
  • Vertical seams: the clock column ends ≈ 540, and the duo/feature/quad seam is at 629. In squares, the seam is at 841, so the composer sets --right-w to 338 and long event titles wrap to two lines.
  • Scrim: #3's pools for now. Adaptive α per screen is needed: p95 luminance under each text box, sampled across the whole drift envelope (AC 17).

Performance budget (TCL, DPR 1.9)

  • ≤ 4 moving layers per screen, and ≤ 2 screens in the DOM. Transform only, with no animated filter or blur.
  • Image size = cell × overscan (1.12) × 1.9, capped at 2400 on the long side. For a hero, that's ≈ 4.8 MP decoded.
  • Release the outgoing screen's images (src="" + remove) after the release window, for the AC 14 soak.
  • Measure first: build hero + drift, prove 60 fps on the tablet, then add the spreads.
